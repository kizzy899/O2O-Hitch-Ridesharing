# 演示手册

## 1. 演示目标
- 用一条完整业务链路覆盖课程要求的八项能力。

## 2. 演示账号
- 乘客：`passenger001 / 123456`
- 司机：`driver001 / 123456`
- 管理员：`admin001 / 123456`

## 3. 演示步骤
### 步骤1：登录（乘客）
```bash
curl -X POST http://localhost:9000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"passenger001","password":"123456"}'
```
获取 `passenger-token`。

### 步骤2：补齐乘客档案
```bash
curl -X POST http://localhost:9000/api/passengers \
  -H "Authorization: Bearer <passenger-token>" \
  -H "Content-Type: application/json" \
  -d '{"passengerId":"passenger001","level":"STANDARD","emergencyContact":"13800009999"}'
```

### 步骤3：发起行程
```bash
curl -X POST http://localhost:9000/api/trips \
  -H "Authorization: Bearer <passenger-token>" \
  -H "Content-Type: application/json" \
  -d '{"passengerId":"passenger001","from":"Campus A","to":"Campus B"}'
```
记录返回 `tripId`。

### 步骤4：查询我的行程列表
```bash
curl "http://localhost:9000/api/trips?passengerId=passenger001" \
  -H "Authorization: Bearer <passenger-token>"
```

### 步骤5：创建订单
```bash
curl -X POST http://localhost:9000/api/orders/create \
  -H "Authorization: Bearer <passenger-token>" \
  -H "Content-Type: application/json" \
  -d '{"tripId":"<tripId>","driverId":"driver001","passengerId":"passenger001"}'
```
记录返回 `orderId`。

### 步骤6：登录（司机）
```bash
curl -X POST http://localhost:9000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"driver001","password":"123456"}'
```
获取 `driver-token`。

### 步骤7：司机接单
```bash
curl -X POST http://localhost:9000/api/orders/<orderId>/accept \
  -H "Authorization: Bearer <driver-token>"
```
预期：`status=ACCEPTED`，`tripStatus=ORDER_ACCEPTED`，`driverAvailable=false`。

### 步骤8A：司机完成订单
```bash
curl -X POST http://localhost:9000/api/orders/<orderId>/complete \
  -H "Authorization: Bearer <driver-token>"
```
预期：`status=COMPLETED`，`tripStatus=ORDER_COMPLETED`，`driverAvailable=true`。

### 步骤8B：取消订单（替代 8A）
```bash
curl -X POST http://localhost:9000/api/orders/<orderId>/cancel \
  -H "Authorization: Bearer <passenger-token>"
```
预期：`status=CANCELLED`，`tripStatus=ORDER_CANCELLED`。

### 步骤9：查询订单详情
```bash
curl http://localhost:9000/api/orders/<orderId> \
  -H "Authorization: Bearer <passenger-token>"
```

### 步骤10：查询我的订单列表
```bash
curl "http://localhost:9000/api/orders?userId=passenger001&status=ACCEPTED" \
  -H "Authorization: Bearer <passenger-token>"
```

### 步骤11：验证越权拦截
```bash
curl "http://localhost:9000/api/orders?userId=passenger002" \
  -H "Authorization: Bearer <passenger-token>"
```
预期：返回角色作用域错误，阻止查询他人订单数据。

### 步骤12：验证司机越权操作拦截
```bash
curl -X POST http://localhost:9000/api/orders/<orderId>/accept \
  -H "Authorization: Bearer <other-driver-token>"
```
预期：返回订单作用域错误，阻止非归属司机接单。

### 步骤13：验证行程详情越权拦截
```bash
curl http://localhost:9000/api/trips/<tripId-of-passenger002> \
  -H "Authorization: Bearer <passenger001-token>"
```
预期：返回行程作用域错误，阻止查询他人行程详情。

### 步骤14：验证司机绑定越权拦截
```bash
curl -X POST "http://localhost:9000/api/trips/<tripId>/match-driver?driverId=driver002" \
  -H "Authorization: Bearer <driver001-token>"
```
预期：返回行程绑定作用域错误，阻止司机绑定非本人 `driverId`。

## 4. 技术点核验
- Eureka：控制台可见服务实例。
- Feign：行程/订单/司机接口联动可观察。
- Config：端口与路由来自配置中心。
- Zuul：所有外部请求统一走 `/api/**`。
- Ribbon：`/api/orders/lb-check` 可用于命中分布展示。
- 认证授权：无 token 或角色不匹配触发拦截。
