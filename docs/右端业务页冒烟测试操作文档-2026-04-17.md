## 7. 建议的手点复核清单（5 分钟版）
1. 登录乘客 -> 发布行程 -> 在“我的行程”确认新 trip。
2. 在“我的订单”确认订单可见（如无可先通过 Console 创建一个）。
3. 切换司机登录 -> “可接行程”看到 `PENDING_ACCEPT` -> 点击接单。
4. 到“我的订单”点击完成 -> 回乘客查看订单详情为 `COMPLETED`。
5. 观察左侧 Console 响应区是否同步展示右侧请求结果。
