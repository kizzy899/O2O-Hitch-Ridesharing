# 接口清单

## 认证服务
### POST /api/auth/login
- 请求：`{username,password}`
- 响应：`{token,userId,role}`

### GET /api/auth/me
- 请求头：`Authorization`
- 响应：`{userId,role}`

## 用户服务
### POST /api/users
- 请求：`{userId,role,nickname,mobile,password}`
- 用途：管理员登记或更新用户资料

### GET /api/users/{userId}
- 用途：查询用户基础资料

### GET /users/internal/{userId}/auth-profile
- 用途：认证服务查询用户认证资料

## 司机服务
### GET /api/drivers/{driverId}/availability
- 用途：查询司机可接单状态

### PUT /api/drivers/{driverId}/availability
- 请求：`{available}`
- 用途：更新司机可接单状态

### PUT /drivers/internal/{driverId}/availability/{available}
- 用途：订单服务内部更新司机可接单状态

## 乘客服务
### POST /api/passengers
- 请求：`{passengerId,level,emergencyContact}`
- 用途：登记或更新乘客资料

### GET /api/passengers/{id}
- 用途：查询乘客基础信息

### GET /passengers/internal/{id}
- 用途：行程服务内部校验乘客档案

## 行程服务
### POST /api/trips
- 请求：`{passengerId,from,to}`
- 用途：乘客发布出行需求
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：乘客仅可提交本人 `passengerId`，管理员可跨用户
- 关键字段：`tripId,status(PUBLISHED),createdAt,updatedAt`

### GET /api/trips/{id}
- 用途：查询行程详情
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：普通乘客仅可查询本人行程，管理员可跨用户

### GET /api/trips?passengerId=xxx&status=xxx
- 用途：按乘客查询行程列表，可按状态过滤
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：乘客仅可查询本人 `passengerId`，管理员可跨用户

### POST /api/trips/{id}/match-driver?driverId=xxx
- 用途：司机或管理员绑定行程与司机
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：司机仅可绑定本人 `driverId`，管理员可跨用户
- 关键字段：`status(MATCHED),driverId`

### POST /trips/internal/{id}/order-accepted
- 用途：订单服务在接单成功后推进行程状态
- 关键字段：`status(ORDER_ACCEPTED)`

### POST /trips/internal/{id}/order-completed
- 用途：订单服务在完成订单后推进行程状态
- 关键字段：`status(ORDER_COMPLETED)`

### POST /trips/internal/{id}/order-cancelled
- 用途：订单服务在取消订单后推进行程状态
- 关键字段：`status(ORDER_CANCELLED)`

## 订单服务
### POST /api/orders/create
- 请求：`{tripId,driverId,passengerId}`
- 用途：创建订单
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：乘客仅可提交本人 `passengerId`，管理员可跨用户
- 关键校验：行程存在、行程归属乘客一致、司机可接单
- 关键字段：`orderId,status(PENDING_ACCEPT),driverNode,tripStatus,driverAvailable`

### POST /api/orders/{id}/accept
- 用途：司机接单
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：司机仅可接自己订单，管理员可跨用户
- 关键联动：调用行程服务推进状态到 `ORDER_ACCEPTED`，调用司机服务更新可接单状态为 `false`
- 关键字段：`status(ACCEPTED),tripStatus(ORDER_ACCEPTED),driverAvailable(false)`

### POST /api/orders/{id}/complete
- 用途：司机完成订单
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：司机仅可完成自己订单，管理员可跨用户
- 关键联动：调用行程服务推进状态到 `ORDER_COMPLETED`，调用司机服务恢复可接单状态为 `true`
- 关键字段：`status(COMPLETED),tripStatus(ORDER_COMPLETED),driverAvailable(true)`

### POST /api/orders/{id}/cancel
- 用途：取消订单
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：乘客仅可取消本人订单，司机仅可取消自己订单，管理员可跨用户
- 关键联动：调用行程服务推进状态到 `ORDER_CANCELLED`，已接单场景恢复司机可接单状态为 `true`
- 关键字段：`status(CANCELLED),tripStatus(ORDER_CANCELLED)`

### GET /api/orders/{id}
- 用途：查询订单详情
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：普通角色仅可查询本人订单，管理员可跨用户

### GET /api/orders?userId=xxx&status=xxx
- 用途：按角色范围查询订单列表，可按状态过滤
- 认证透传：`X-User-Id`、`X-User-Role`
- 作用域规则：普通角色仅可查询本人 `userId`，管理员可跨用户

### GET /api/orders/lb-check
- 参数：`times`,`driverId`
- 用途：Ribbon 命中分布演示
