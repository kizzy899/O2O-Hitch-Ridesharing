# 06 容错处理与负载均衡

## 本阶段目标
- 建设可演示的 Ribbon 负载均衡调用。
- 建设 Feign fallback 兜底处理。

## 涉及模块
- `order-service`
- `driver-service`
- `trip-service`

## 对应关键代码位置
- `order-service/src/main/java/com/o2o/hitch/order/OrderServiceApplication.java`
- `order-service/src/main/java/com/o2o/hitch/order/service/OrderService.java`
- `order-service/src/main/java/com/o2o/hitch/order/client/DriverClientFallback.java`
- `trip-service/src/main/java/com/o2o/hitch/trip/client/UserClientFallback.java`

## 核心类与配置说明
- `@LoadBalanced RestTemplate` 通过服务名访问实例并触发负载均衡。
- `GET /api/orders/lb-check` 通过多次调用采样命中结果。
- Feign fallback 在下游异常时返回降级数据，避免链路直接失败。

## 关键接口说明
- `GET /api/orders/lb-check?times=8&driverId=driver001`

## 模块之间调用关系
- `order-service` -> `driver-service`（Ribbon）
- `trip-service` -> `user-service`（Feign fallback）

## 文字版流程说明
1. 调用 `lb-check` 触发多次内部请求。
2. 请求按实例列表分配到目标服务。
3. 返回结果中的节点信息用于观察命中分布。
4. 当下游异常时返回 fallback 数据并保持主流程可继续。

## 本阶段能力结果
- 系统具备基础容错与负载均衡演示能力。
