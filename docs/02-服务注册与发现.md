# 02 服务注册与发现

## 本阶段目标
- 建设 Eureka Server。
- 让业务服务作为 Eureka Client 完成注册与发现。

## 涉及模块
- `eureka-server`
- `config-server`
- `gateway-zuul`
- 全部业务服务

## 对应关键代码位置
- `eureka-server/src/main/java/com/o2o/hitch/eureka/EurekaServerApplication.java`
- `eureka-server/src/main/resources/application.yml`
- `config-repo/application.yml`

## 核心类与配置说明
- `@EnableEurekaServer` 启用注册中心能力。
- `eureka.client.service-url.defaultZone` 统一指向 `http://localhost:8761/eureka/`。
- 各服务通过 `spring.application.name` 注册服务名。

## 关键接口说明
- Eureka 控制台：`http://localhost:8761`

## 模块之间调用关系
- Client 服务启动后向 Eureka 注册自身。
- 网关、Feign、Ribbon 基于注册信息进行发现与调用。

## 文字版流程说明
1. 启动 eureka-server。
2. 启动各服务，服务向 Eureka 上报实例。
3. 调用方根据服务名检索可用实例。

## 本阶段完成后系统获得了什么能力
- 服务实例地址与调用方解耦，具备基础服务治理能力。
