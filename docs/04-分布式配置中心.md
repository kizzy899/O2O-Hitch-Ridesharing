# 04 分布式配置中心

## 本阶段目标
- 建设 Config Server。
- 客户端服务从配置中心读取端口、路由、认证参数等配置。

## 涉及模块
- `config-server`
- `config-repo`
- 全部客户端服务（含网关）

## 对应关键代码位置
- `config-server/src/main/java/com/o2o/hitch/config/ConfigServerApplication.java`
- `config-server/src/main/resources/application.yml`
- `config-repo/*.yml`
- 各服务 `bootstrap.yml`

## 核心类与配置说明
- Config Server 使用 `native` profile，搜索路径 `file:../config-repo`。
- `bootstrap.yml` 中设置 `spring.cloud.config.uri=http://localhost:8888`。
- 公共配置在 `config-repo/application.yml`，服务差异配置在 `config-repo/<service>.yml`。

## 关键接口说明
- 配置健康：`http://localhost:8888/actuator/health`
- 配置读取：`http://localhost:8888/<service>/default`

## 模块之间调用关系
- 客户端启动时先访问 Config Server 拉取配置。
- Config Server 读取 config-repo 返回配置内容。

## 文字版流程说明
1. 启动 config-server。
2. 启动业务服务，业务服务读取配置中心。
3. 服务按远程配置完成端口、路由、鉴权参数初始化。

## 本阶段完成后系统获得了什么能力
- 配置集中管理，便于统一维护与课堂演示环境切换。
