# 项目约束文档

## 1. 项目目标
- 建设教学演示型 O2O 顺风车微服务系统。
- 以“结构标准、职责明确、链路清晰、可讲解、可验证”为优先目标。
- 在同一仓库下独立目录建设，不修改既有历史目录业务实现。

## 2. 技术边界
- Java 8 + Spring Boot 2.3.12.RELEASE + Spring Cloud Hoxton.SR12。
- 必选能力：Eureka、OpenFeign、Spring Cloud Config、Zuul、Ribbon、JWT 认证授权。
- API 风格：Spring MVC RESTful。

## 3. 模块职责边界
- 注册中心：`eureka-server`
- 配置中心：`config-server`
- 统一入口：`gateway-zuul`
- 认证：`auth-service`
- 用户域：`user-service`
- 司机域：`driver-service`
- 乘客域：`passenger-service`
- 行程域：`trip-service`
- 订单域：`order-service`
- 公共能力：`common`

## 4. 开发顺序约束
1. 治理文档先完成。
2. 再进入 Java Web 基础能力。
3. 再接入注册发现、配置中心、业务调用、网关、认证、闭环。
4. 每完成一个功能，立即补计划与测试文档。

## 5. 交付约束
- 每阶段必须有代码产出 + 文档产出 + 验证说明。
- 文档中必须可定位到代码路径与关键接口。
