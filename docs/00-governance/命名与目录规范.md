# 命名与目录规范

## 1. 目录命名
- 服务目录统一：`*-service`。
- 基础模块目录：`common`、`config-repo`、`docs`、`scripts`、`frontend`。

## 2. 包命名
- 根包：`com.o2o.hitch.<module>`。
- 子包：`controller/service/client/config/exception/dto/vo/entity`。

## 3. 类命名
- 控制器：`*Controller`
- 服务：`*Service`
- 配置：`*Config`
- 客户端：`*Client`
- 异常：`*Exception`

## 4. 文件命名
- 阶段文档：`01-...` 到 `08-...`
- 计划文档：`<模块>-plan.md`
- 测试文档：`<模块>-test.md`

## 5. 约束
- 命名应清晰表达职责，不使用模糊缩写。
