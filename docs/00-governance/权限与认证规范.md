# 权限与认证规范

## 1. 认证模型
- 统一登录入口：`POST /api/auth/login`。
- 登录成功签发 JWT，携带 `userId` 与 `role`。

## 2. 鉴权模型
- 网关负责 token 校验与身份透传。
- 服务负责业务权限校验。

## 3. 角色模型
- `PASSENGER`：可发起行程、创建订单。
- `DRIVER`：可执行接单动作。
- `ADMIN`：具备全量演示权限。

## 4. 受保护接口示例
- 行程创建：`POST /api/trips`
- 订单创建：`POST /api/orders/create`
- 订单接单：`POST /api/orders/{id}/accept`

## 5. 安全要求
- 不接受明文 token 以外的身份凭证绕过。
- 文档和日志不展示完整 token。
