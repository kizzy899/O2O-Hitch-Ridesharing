# 文档规范

## 1. 文档体系
- 治理文档：`docs/00-governance/`
- 阶段文档：`docs/01` 到 `docs/08`
- 功能计划：`docs/plans/`
- 功能测试：`docs/tests/`
- 操作记录：`docs/kizy/`

## 2. 模板要求
- 计划文档使用 docs-skill plan-template 结构：
  - Summary
  - Key Changes
  - Public Interfaces
  - Data Mapping
  - Test Plan
  - Assumptions
- 测试文档使用 docs-skill operation-template 结构：
  - 目标与边界
  - 计划先行记录
  - 实施记录
  - 测试记录
  - 改动清单
  - 结论

## 3. 内容要求
- 必须可定位到代码文件。
- 必须可映射到接口与流程。
- 必须写明本阶段能力收获。
