# 配置管理规范

## 1. 配置中心原则
- 统一由 `config-server` 管理。
- 配置源采用 `config-repo` native 模式。

## 2. 配置分层
- 公共配置：`config-repo/application.yml`
- 服务配置：`config-repo/<service>.yml`

## 3. 命名规范
- 服务名与 `spring.application.name` 保持一致。
- 安全参数统一前缀：`security.jwt.*`

## 4. 环境规范
- 当前默认环境：`default/dev`。
- 增加环境时保持同名文件结构（如 `<service>-test.yml`）。

## 5. 变更流程
1. 修改 `config-repo`。
2. 文档记录配置项用途与默认值。
3. 执行健康检查确认服务正常读取。
