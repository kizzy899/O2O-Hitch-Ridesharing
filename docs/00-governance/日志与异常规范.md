# 日志与异常规范

## 1. 日志规范
- 关键节点记录：请求入口、业务关键动作、异常分支。
- 推荐字段：traceId、serviceName、path、userId、role、耗时。
- 禁止记录敏感信息（完整 token、密码明文）。

## 2. 异常规范
- 业务异常：`BusinessException(code, message)`。
- 系统异常：由 `GlobalExceptionHandler` 统一转换。
- 网关鉴权异常：统一 401 响应。

## 3. 处理策略
- 参数错误：直接返回 4001。
- 认证失败：返回 4010。
- 授权失败：返回 403x。
- 未知异常：返回 5000。

## 4. 验证要求
- 文档需说明每个模块的主要异常分支。
- 测试文档需记录异常场景验证。
