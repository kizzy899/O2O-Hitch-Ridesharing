# 接口规范文档

## 1. URL 规范
- 统一前缀由网关提供：`/api`。
- 资源命名：`/users`、`/drivers`、`/passengers`、`/trips`、`/orders`。
- 动作型子路径：`/orders/create`、`/orders/{id}/accept`。

## 2. 请求规范
- JSON 请求头：`Content-Type: application/json`。
- 鉴权头：`Authorization: Bearer <token>`。
- 透传头：`X-User-Id`、`X-User-Role`（网关注入）。

## 3. 响应规范
- 统一结构：
  - `code`: 整型业务码
  - `message`: 业务说明
  - `data`: 业务数据
  - `timestamp`: 毫秒时间戳
  - `traceId`: 链路追踪ID

## 4. 错误码规范
- `0`：成功
- `4001`：参数校验失败
- `4010`：未认证/无效令牌
- `403x`：角色权限不足
- `5000`：系统错误

## 5. 示例
- 登录成功：返回 token、userId、role。
- 未携带 token：网关返回 4010。
