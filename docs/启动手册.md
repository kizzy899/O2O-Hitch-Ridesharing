# 启动手册

## 1. 环境准备
- JDK 8
- Maven 3.6+
- MySQL 5.7+
- 建议已安装 curl 便于接口验证

## 2. 数据初始化
```sql
source db/init.sql;
```

## 3. 启动顺序
### 方案A：一键启动（推荐）
- Windows：`./scripts/start-all.ps1`
- Linux/macOS：`chmod +x ./scripts/start-all.sh && ./scripts/start-all.sh`

### 方案B：按模块启动
1. `config-server`
2. `eureka-server`
3. `gateway-zuul`
4. `auth-service`
5. 业务服务：`user-service`、`driver-service`、`passenger-service`、`trip-service`、`order-service`

## 4. 健康检查
- Eureka：`http://localhost:8761`
- Config：`http://localhost:8888/actuator/health`
- Gateway：`http://localhost:9000/actuator/health`

## 5. 主链路最小验证
1. 登录获取 token。
2. 发布行程并创建订单。
3. 司机接单后确认 `driverAvailable=false`。
4. 完成或取消订单后确认 `driverAvailable=true`（完成场景）或状态已取消（取消场景）。

## 6. 常见问题
- `mvn` 不可用：请先安装 Maven 并配置 PATH。
- 服务未注册：确认 Eureka 启动后再启动业务服务。
- 网关 401：检查是否携带 `Authorization: Bearer <token>`。
