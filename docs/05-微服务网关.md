# 05 微服务网关

## 本阶段目标
- 使用 Zuul 建设统一入口。
- 实现过滤器能力：JWT 校验、角色校验、请求头透传。

## 涉及模块
- `gateway-zuul`
- `config-repo/gateway-zuul.yml`
- `common`（JWT 支撑）

## 对应关键代码位置
- `gateway-zuul/src/main/java/com/o2o/hitch/gateway/GatewayZuulApplication.java`
- `gateway-zuul/src/main/java/com/o2o/hitch/gateway/filter/AuthPreFilter.java`
- `config-repo/gateway-zuul.yml`

## 核心类与配置说明
- `@EnableZuulProxy` 开启网关代理。
- `zuul.prefix=/api` 统一入口前缀。
- `AuthPreFilter` 对开放路径放行，其余路径强制校验 `Authorization`。
- 校验通过后透传 `X-User-Id`、`X-User-Role` 到下游。

## 关键接口说明
- 网关入口：`/api/**`
- 开放路径：`/api/auth/login`
- 受保护路径：`/api/trips/**`、`/api/orders/**` 等

## 模块之间调用关系
- 客户端 -> gateway-zuul -> 业务服务

## 文字版流程说明
1. 请求进入网关。
2. 过滤器检查 token 与角色。
3. 合法请求转发到目标服务，不合法请求直接返回 401。

## 本阶段完成后系统获得了什么能力
- 获得统一入口与统一访问控制能力，便于集中治理与安全演示。
