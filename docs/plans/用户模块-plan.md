# 用户模块建设计划

## 阶段目标
- 建设用户基础资料能力，为认证与行程/订单链路提供稳定用户数据。

## 模块建设范围
- 服务：`user-service`
- 接入：`gateway-zuul`

## 能力实现清单
1. 新增 `UserRequest` 参数对象与校验规则。
2. 建设用户资料查询能力：按 `userId` 查询。
3. 建设用户资料登记能力：管理员角色可新增/更新用户。
4. 内置乘客/司机/管理员基础用户，便于联调演示。

## 接口说明
1. `POST /api/users`（管理员）
2. `GET /api/users/{userId}`

## 测试设计
1. 不存在用户查询应返回 `USER_NOT_FOUND`。
2. 管理员可创建或更新用户。
3. 非管理员调用创建接口应被拒绝。

## 结果验证
- 已新增 `UserServiceTest` 覆盖不存在用户查询场景。
- 受环境限制，待 Maven 可用后执行模块自动化测试与联调。
