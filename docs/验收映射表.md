# 验收映射表

| 课程要求 | 已实现内容 | 代码定位 | 验证方式 |
|---|---|---|---|
| Java Web 开发 | REST 控制器、统一返回体、全局异常 | `common` + 各服务 `controller` | 调用接口检查返回结构 |
| 服务注册与发现 | Eureka Server + Client 注册 | `eureka-server` + `config-repo/application.yml` + `scripts/start-all.ps1` | 访问 `/eureka/apps` 核验注册实例数 |
| RPC 调用 | OpenFeign + fallback，含订单-行程、订单-司机双向状态联动 | `trip-service/client`、`order-service/client` | 调用接单/完成/取消接口观察联动 |
| 分布式配置中心 | Config Server + native 配置仓 | `config-server` + `config-repo` | 查看服务读取端口/路由配置 |
| 微服务网关 | Zuul 路由与前置过滤器 | `gateway-zuul` + `AuthPreFilter` | 请求统一走 `/api/**` |
| 容错与负载均衡 | Ribbon + fallback | `order-service` | 调用 `/api/orders/lb-check` |
| 统一认证与授权 | JWT 登录、网关校验、角色限制、用户作用域校验（含订单与行程详情归属校验） | `auth-service` + `gateway-zuul` + `trip/order` controller | 无 token/越权访问验证 |
| 综合业务系统 | 登录-乘客-行程-订单完整闭环（接单、完成、取消）+ 行程/订单列表查询 | `auth/passenger/trip/order/driver` | 按 `docs/演示手册.md` 逐步执行 |
